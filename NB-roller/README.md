# NB抽学号系统（NB-roller）V1.0

**摘要：** 本文详细介绍了一款功能强大的"NB抽学号系统"（NB-roller），该系统在原有抽学号工具基础上，新增了男女生模式、转盘抽取模式（平面圆形和立体环形+翻卡片两种）、节日UI、PK模式（支持男女生对战，带击剑动画）、Excel导入支持男女生、抽取成功后启动音效和名字播报功能（TTS），以及懒加载机制，全面提升用户体验。

## 📌 一、项目简介

"NB抽学号系统"（NB-roller）是一款专为教育场景设计的智能学号抽取工具。系统采用**现代Web技术栈**，结合**Web Audio API**实现音效，通过丰富的CSS动画和交互设计，为课堂互动带来了前所未有的趣味体验。本系统在原有功能基础上，进行了全面的功能扩展和体验升级。

## 📈 二、核心功能特性

### 1. 标准抽取模式
- **快速抽取**：点击后学号快速滚动，再次点击停止
- **历史记录**：自动保存抽取历史，支持查看和清空
- **重复抽取控制**：可选择是否允许重复抽取

### 2. 男女生模式
- **性别分组**：自动根据性别对学生进行分组
- **独立抽取**：可选择仅抽取男生、女生或全部学生
- **性别标识**：支持Excel导入时识别性别信息

### 3. 转盘抽取模式
- **平面圆形转盘**：标准圆形转盘，带指针和颜色分区
- **立体环形转盘**：3D立体效果，学生信息环绕分布
- **翻卡片效果**：抽取结果以翻卡片动画展示
- **音效配合**：转动和翻转时播放相应音效

### 4. PK模式（男女生对战）
- **击剑动画**：PK开始时播放击剑交锋动画
- **实时计分**：支持男女生队伍实时计分对战
- **音效配合**：PK过程配有击剑音效
- **公平对战**：支持男女生分组公平对战

### 5. 节日主题UI
- **春节主题**：红色系，包含灯笼、鞭炮等装饰
- **圣诞节主题**：红绿配色，包含圣诞树、雪花、礼物等装饰
- **情人节主题**：粉色系，包含爱心等装饰
- **万圣节主题**：橙色系，包含南瓜灯、幽灵等装饰
- **动态装饰**：节日元素动态添加，增强节日氛围

### 6. 音效系统
- **Web Audio API**：使用原生Web Audio API实现音效
- **多种音效**：包含点击、抽取、庆祝、翻转、击剑等多种音效
- **音效开关**：支持音效开关控制
- **TTS功能**：抽取成功后可播报学生姓名

### 7. Excel导入功能
- **多格式支持**：支持.xlsx、.xls、.csv格式
- **性别识别**：自动识别性别信息并分组
- **数据预览**：导入前可预览数据内容
- **格式灵活**：支持"学号,姓名,性别"或"学号,姓名"格式

### 8. 懒加载机制
- **按需加载**：组件按需加载，提升性能
- **模块化设计**：各功能模块独立，便于维护
- **减少初始加载时间**：优化用户体验

## 🎮 四、使用方法

### 1. 基本使用
- 访问 `index.html` 页面开始使用
- 通过顶部模式选择按钮切换不同抽取模式
- 使用"导入Excel"功能导入学生名单
- 点击"开始抽取"进行学号抽取

### 2. Excel导入格式
支持以下格式的Excel文件：
```
学号    姓名    性别
001     张三    男
002     李四    女
003     王五    男
```
或
```
学号    姓名
001     张三
002     李四
003     王五
```

### 3. 功能设置
- **音效控制**：勾选"音效"开关控制音效播放
- **名字播报**：勾选"TTS"开关启用名字播报功能
- **节日主题**：点击"节日主题"按钮选择不同节日UI

## 🚀 五、API接口

### 主应用方法
- `switchMode(mode)` - 切换抽取模式
- `startDraw()` - 开始标准模式抽取
- `stopDraw()` - 停止标准模式抽取
- `startGenderDraw()` - 开始男女生模式抽取
- `importStudents(students)` - 导入学生数据
- `applyFestivalTheme(theme)` - 应用节日主题

### 组件方法
- `PKMode.setPlayers(malePlayers, femalePlayers)` - 设置PK模式玩家
- `RouletteMode.setPlayers(players)` - 设置转盘模式玩家
- `RouletteMode.switchMode(mode)` - 切换转盘模式('flat' 或 '3d')

## 🌟 六、创新亮点

### 1. 击剑动画
PK模式开始时播放精美的击剑动画，增强对战氛围，使用CSS动画实现流畅效果。

### 2. 立体转盘
创新的3D立体转盘设计，学生信息环绕分布，提供沉浸式抽取体验。

### 3. 翻卡片效果
抽取结果以翻卡片动画展示，增加悬念感和趣味性。

### 4. 智能TTS
抽取成功后自动播报学生姓名，支持中文语音合成。

### 5. 节日主题系统
动态节日装饰系统，根据不同节日自动添加相应装饰元素。
