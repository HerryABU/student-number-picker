### ✨ 核心功能亮点

#### 1. 📂 **双模式操作：学号范围 vs. 名单导入**

系统提供两种灵活的学号管理方式，满足不同需求。

* **学号范围模式**：适用于没有固定名单的场景。您只需输入起始和结束学号（例如 1 ~ 40），系统即可在该范围内进行抽取。
* **名单导入模式（核心功能）**：这才是真正的“智能”所在！
  * **Excel一键导入**：您可以将班级学生名单（`.xlsx` 或 `.xls` 格式）通过 **拖拽** 或 **点击上传** 的方式导入系统。系统会自动识别A列为学号，B列为姓名。
  * **学号姓名绑定**：抽取结果将**同时显示学号和姓名**，彻底告别“12号是谁？”的尴尬，点名过程一目了然，效率倍增。

#### 2. 🗂️ **多名单组管理**

告别单一班级的限制！系统支持创建和管理**多个独立的学生分组**。

* 您可以创建“高一1班”、“高一2班”、“英语兴趣小组”等多个名单。
* 通过顶部的标签页一键切换，不同班级的数据互不干扰。
* **所有名单和设置均自动保存**至浏览器，刷新页面或下次访问依然存在。

#### 3. 🌙 **全新暗黑模式**

保护您的眼睛，让体验更舒适！

* 点击右上角的月亮/太阳图标，即可在**浅色模式**与**深邃的暗黑模式**之间一键切换。
* 完整的暗黑主题适配，包括背景、卡片、按钮、文本和输入框，让夜间教学或活动更加舒适。

#### 4. 🔀 **多种抽取模式**

满足您在不同场景下的需求。

* **单次抽取**：点击“抽取学号”按钮，获取一个随机学号（或姓名）。
* **快速抽取（滚动）**：点击“开始抽取”，学号将快速滚动，模拟“转盘”效果，点击“停止”后记录结果。
* **连抽N次**：设置抽取次数（如5次），系统将连续抽取并展示结果。
* **批量抽取**：设置抽取人数，系统将一次性抽取多人，并以列表形式展示，适用于小组分配。

#### 5. 🔁 **不重复抽取**

确保公平性，避免重复提问。

* 开启此选项后，已被抽取的学号（或姓名）将从候选池中移除，确保在本轮抽取中**不会再次出现**。

#### 6. 🎯 **智能概率权重控制**

实现“重点抽查”或“分层抽样”。

* 您可以为不同的学号区间设置不同的抽取概率（权重）。
* 例如：让1-20号有80%的概率被抽到，21-40号只有20%的概率，实现更有针对性的课堂互动。

#### 7. 🎉 **丰富的动画反馈**

让每一次抽取都充满仪式感和趣味性。

* **翻转动画**：抽取时，数字区域会进行酷炫的3D翻转，如同真实的抽奖转盘。
* **高亮闪烁**：最新抽取的学号会在历史记录中脉冲闪烁，清晰可见。
* **庆祝动画**：当所有学号都被抽取完毕时，系统会触发全屏的“彩纸”动画，并显示祝贺信息，极大地提升了互动感和仪式感。

#### 8. 🔗 **URL参数同步**

配置即分享，体验无缝衔接。

* 您的所有设置（当前分组、学号范围、字体大小、主题等）都会自动同步到浏览器的URL地址栏。

### 🧭 详细使用指南

#### **第一步：进入设置页面**

打开系统后，您会看到一个清晰的设置界面。

1. **选择模式**：在“学号范围”和“名单导入”中选择一种。
  * 选择“学号范围”：输入起始和结束学号。
  * 选择“名单导入”：点击“上传Excel文件”按钮，或直接将您的 `.xlsx` 文件拖拽到指定区域。
2. **创建分组**：在“学生名单管理”区域，点击“+ 新建分组”按钮，为您的名单命名（如“高三3班”）。
3. **管理名单**：
  * 上传文件后，名单会自动加载到当前分组。
  * 您可以在每个学生姓名后点击 **🗑️ 删除图标** 来移除单个学生。
  * 也可以在分组标签页上点击 **🗑️** 来删除整个分组。
4. **高级设置**：
  * **不重复抽取**：建议开启。
  * **概率权重**：点击“添加概率范围”，输入学号区间和对应的权重百分比。
  * **字号设置**：通过滑块调节学号和姓名的显示大小，确保在大屏幕投影时也能清晰可见。
  * **暗黑模式**：点击右上角图标切换。
5. **开始抽取**：一切设置完毕后，点击“开始抽取”按钮，进入抽取页面。

#### **第二步：进行抽取操作**

在抽取页面，您将看到一个简洁而醒目的界面。

1. **查看结果**：中央的大号区域会显示当前抽取的学号和姓名。
2. **选择模式**：使用下方的按钮选择“单次抽取”、“快速抽取”或“批量抽取”。
3. **执行抽取**：
  * **单次/批量**：点击“抽取学号”按钮。
  * **快速抽取**：点击“开始抽取”按钮，学号开始滚动，再次点击“停止抽取”按钮确认结果。
4. **查看历史**：页面下方会实时显示所有已抽取的学号和姓名，最新结果会高亮显示。
5. **返回设置**：随时可以点击“返回设置”按钮，调整您的配置。
