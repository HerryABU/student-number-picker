## 🚀 重磅升级：从 V4.3.2 到 V5.3.2 的核心进化

相较于旧版本，新系统实现了质的飞跃。以下是本次升级的几大核心亮点：

### 🔥 **1. 革命性“名单导入”模式（全新功能）**

*   **旧版痛点**：仅支持学号范围输入，无法关联学生姓名，抽取后仍需手动核对。
*   **新版进化**：**新增“名单导入”模式**！
    *   支持上传 `.xlsx` 或 `.xls` 格式的 Excel 学生名单。
    *   系统自动识别 A 列为学号，B 列为姓名。
    *   抽取结果将**同时显示学号和姓名**，彻底告别“学号对应谁”的烦恼，点名过程一目了然，效率倍增。

### 📚 **2. 多名单组管理（全新功能）**

*   **旧版痛点**：所有设置和数据都是全局的，无法为不同班级或小组分别管理。
*   **新版进化**：**支持创建和管理多个学生分组**！
    *   可创建“高一1班”、“高一2班”、“兴趣小组”等多个独立名单。
    *   通过标签页一键切换，不同班级的数据互不干扰。
    *   所有名单和设置均自动保存至浏览器，刷新或下次访问依然存在。

### 🌙 **3. 全新暗黑模式（全新功能）**

*   **旧版痛点**：仅提供单一的浅色主题，在光线较暗的环境下使用易造成视觉疲劳。
*   **新版进化**：**重磅加入“暗黑模式”**！
    *   点击右上角的月亮/太阳图标，即可在**浅色模式**与**深邃的暗黑模式**之间一键切换。
    *   完整的暗黑主题适配，包括背景、卡片、按钮、文本和输入框，保护您的眼睛，让夜间教学或活动更加舒适。

### 🎯 **4. 概率权重控制全面优化（功能增强）**

*   **旧版实现**：基础的概率区间设置。
*   **新版进化**：**更智能、更严谨的权重控制**！
    *   新增**范围边界自动校验**：当学号范围调整时，相关的概率区间会自动适配，防止出现无效设置。
    *   **严格的输入验证**：对权重值、区间范围进行实时检查，确保数据的有效性，避免因错误配置导致程序异常。

### 🎉 **5. 动画与交互体验全面升级**

*   **旧版实现**：基础的庆祝动画和抽取效果。
*   **新版进化**：**更炫酷、更具反馈感的视觉盛宴**！
    *   **批量抽取庆祝**：当一次性抽取多人（如5人以上）时，系统会触发特殊的庆祝动画，并显示“成功抽取X人！”的个性化提示，仪式感拉满。
    *   **更流畅的多抽动画**：优化了“连抽”模式的动画效果，逐个展示结果，过程更清晰、更具观赏性。
    *   **顶部动态渐变条**：页面顶部增加了流动的彩色渐变装饰条，科技感十足。

## 💡 功能亮点总览

### ✅ 双模式操作：学号范围 vs. 名单导入（**全新**）
- **学号范围模式**：快速设置起止学号。
- **名单导入模式**：上传Excel，**自动关联姓名**，实现精准点名。

### ✅ 多名单组管理（**全新**）
- 支持创建、切换和管理多个学生分组。
- 数据持久化存储，刷新不丢失。

### ✅ 暗黑模式（**全新**）
- 一键切换浅色/深色主题，适应不同环境。

### ✅ 多种抽取模式
- **单次抽取**、**快速抽取**、**连抽N次**、**批量抽取**，满足各种需求。

### ✅ 不重复抽取
- 确保每个学号在本轮抽取中仅出现一次。

### ✅ 智能概率权重控制
- 为不同学号区间设置抽取概率。
- **自动校验区间范围**，防止配置错误。

### ✅ 字体与样式自定义
- 自由选择全局和学号字体（Inter, Arial, 楷体等）。
- 滑动调节字号，实时预览。

### ✅ 丰富的动画反馈
- **抽取结果高亮**：最新结果脉冲闪烁。
- **庆祝动画**：全员抽取完毕或批量抽取成功时自动触发。
- **多抽动画**：全屏半透明背景，逐个展示结果。

### ✅ URL 参数同步
- 所有配置（包括当前分组、学号范围、字体、主题等）均同步到URL，方便分享与恢复。
