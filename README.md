# NB抽学号系统 (NB-roller)

## 简介

NB抽学号系统是一个功能强大、界面美观的在线随机抽取工具，专为教育场景设计。支持多种抽取模式、性别筛选、节日主题、声音效果和PK对战等多种功能，满足不同场景下的抽取需求。

## 功能特性

### 基础功能
- **范围模式**：在指定学号范围内随机抽取
- **名单模式**：从Excel/CSV导入的学生名单中抽取
- **单次抽取**：抽取一个学生
- **连抽模式**：一次性抽取多个学生
- **批量抽取**：连续多次抽取
- **不重复抽取**：确保同一学生不会被重复抽中

### 高级功能
- **性别筛选模式**：支持全部/男生/女生三种抽取模式
- **转盘模式**：包含平面转盘和立体转盘两种视觉效果
- **翻卡片模式**：抽取结果以翻卡片形式展示
- **PK模式**：支持男女生对战，带击剑动画效果
- **惊心动魄模式**：抽取过程带有闪烁动画效果
- **节日主题**：支持春节、端午、中秋、重阳、国庆、圣诞、万圣节等节日UI
- **声音效果**：使用Web Audio API实现音效
- **姓名播报**：TTS功能朗读被抽中的学生姓名
- **深色模式**：支持深色/浅色主题切换

### 数据管理
- **Excel/CSV导入**：支持多种格式的学生名单导入
- **多分组管理**：可创建多个学生分组
- **历史记录**：保存抽取历史
- **数据持久化**：抽取记录本地保存

## 安装与使用

### 本地运行
1. 克隆或下载项目文件
2. 直接打开 `index.html` 文件即可使用
3. 或使用本地服务器运行（推荐）

### 通过服务器运行
```bash
# 使用Python启动本地服务器
python -m http.server 8000

# 或使用Node.js的http-server
npx http-server
```

## 使用说明

### 1. 设置阶段
- 选择操作模式（范围模式或名单模式）
- 配置抽取参数（学号范围、抽取数量等）
- 选择抽取模式（单次/连抽/批量）
- 选择性别模式（全部/男生/女生）
- 选择特殊模式（转盘/翻卡片/PK等）
- 选择节日主题

### 2. 抽取阶段
- 点击相应按钮进行抽取
- 查看抽取结果
- 查看历史记录

### 3. 数据管理
- 通过Excel/CSV导入学生名单
- 管理学生分组
- 清空历史记录

## 功能详情

### 1. 性别筛选模式
- **全部模式**：抽取所有学生
- **男生模式**：仅抽取男生
- **女生模式**：仅抽取女生
- 在Excel导入时支持性别标识

### 2. 转盘模式
- **平面转盘**：标准圆形转盘
- **立体转盘**：3D侧面环形效果
- 带有转盘音效和旋转动画

### 3. 翻卡片模式
- 结果以卡片翻转形式展示
- 增加抽取的趣味性

### 4. PK模式
- 男女生对战功能
- 开始时有击剑动画效果
- 支持多VS多对战

### 5. 节日主题
- **春节**：红色主题，灯笼、红包等元素
- **端午**：绿色主题，龙舟、粽子等元素
- **中秋**：紫色主题，月亮、月饼等元素
- **重阳**：橙色主题，登山、菊花等元素
- **国庆**：红色主题，国旗、烟花等元素
- **圣诞**：绿色主题，圣诞树、礼物等元素
- **万圣节**：紫色/橙色主题，南瓜灯、鬼魂等元素

### 6. 音效系统
- 使用Web Audio API实现
- 支持抽取音效、庆祝音效、PK音效等
- 可开关音效和TTS功能

### 7. 惊心动魄模式
- 抽取过程中有闪烁动画效果
- 增加紧张刺激感

## Excel导入格式

支持以下列名的Excel/CSV文件：
- `id` 或 `学号`：学生学号
- `name` 或 `姓名`：学生姓名
- `gender` 或 `性别`：学生性别（male/female）

示例：
```
id, name, gender
1, 张三, male
2, 李四, female
3, 王五, male
```
