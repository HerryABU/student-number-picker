# 🚀 **智能学号抽取系统 V5.7.4 综合指南：从网页到桌面，功能与体验的全面进化**

在经历了从 V5.3.2 到 V5.7.3 的功能爆发式增长后，我们迎来了一个**兼具稳定性、完整性与跨平台能力**的里程碑版本——**V5.7.4**。此版本不仅修复了影响深远的URL同步漏洞，更推出了独立的桌面应用程序，将这款强大的工具从浏览器中解放，带来了前所未有的便捷与专业体验。

本文将为您全面解析 V5.7.4 版本的**所有功能**，并详细介绍其**全新的桌面应用形态**。

---

### 🔧 **一、核心功能全面回顾：一个功能完备的抽取系统**

V5.7.4 继承了 V5.7.3 及之前版本的所有强大功能，是一个真正意义上的“智能”抽取系统。

#### ✅ **1. 双模式操作，灵活适应各种场景**
*   **学号范围模式**：最经典的模式。只需输入起始和结束学号（如1-40），系统即可在此范围内进行随机抽取，适用于班级学号连续的情况。
*   **名单导入模式**：更智能、更实用的模式。支持通过**点击或拖拽**上传 `.xlsx` 或 `.xls` 格式的Excel文件。系统会自动读取A列（学号）和B列（姓名），实现学号与姓名的精准匹配，抽取结果一目了然。

#### ✅ **2. 多名单组管理，轻松应对多班级教学**
系统内置强大的分组管理功能。您可以：
*   **创建分组**：为不同班级或课程创建独立的名单组。
*   **切换分组**：在不同分组间快速切换，一键加载对应的学生名单。
*   **重命名/删除分组**：灵活管理您的所有名单。
*   **数据持久化**：所有分组和学生名单数据均自动保存在本地（`localStorage`），刷新或重启应用后依然存在。

#### ✅ **3. 多种抽取模式，满足不同需求**
*   **单次抽取**：点击一次，抽取一个学号，简单直接。
*   **快速抽取**：点击后进入“滚动”状态，学号快速变化，再次点击停止，增添紧张感和趣味性。
*   **连抽N次**：一次性抽取设定次数（可配置）的学号。V5.7.3引入的**全屏动态效果**让每一次抽取都充满仪式感，结果以动画形式逐一展示。
*   **批量抽取**：**全新功能！** 专为需要一次性选出多人的场景设计。在设置中指定人数（如3人），系统将**一次性**为您抽取指定数量的、**不重复**的学号，并以全屏动画效果展示，结果清晰明了。

#### ✅ **4. 智能不重复抽取与历史记录**
*   **不重复抽取**：开启此功能后，系统会自动记录已抽取的学号，确保在本轮使用中，每个学生都有且仅有一次被抽中的机会，真正实现公平公正。
*   **历史记录**：所有抽取结果都会在主界面下方以标签形式实时显示。最新抽取的结果会有脉冲动画高亮，方便您快速回顾。

#### ✅ **5. 智能概率权重控制（URL同步）**
*   **自定义权重**：您可以为不同的学号范围设置不同的抽取“权重”。例如，将“1-10号”设置为80%的概率，而“11-40号”为20%的概率，实现更有策略的抽取。
*   **配置持久化**：所有设置，包括复杂的概率权重，都会自动同步到应用内部状态。**（注：在桌面应用中，此功能体现为配置的本地保存和恢复，而非URL同步）**

#### ✅ **6. 庆祝动画与沉浸式交互**
*   **全员抽取完毕**：当所有学号都被抽取完时，系统会自动触发全屏的庆祝动画，伴随着飘落的彩带（confetti）和弹出的消息，为课堂画上一个欢乐的句号。
*   **动态视觉效果**：从抽取结果的“翻转”、“弹入”动画，到“连抽”和“批量抽取”的全屏动态展示，整个过程充满悬念与乐趣，极大地提升了课堂的互动氛围。

#### ✅ **7. 个性化设置**
*   **深色/浅色主题**：一键切换，保护您的眼睛，适应不同的光照环境。
*   **字号调节**：通过滑块自由调节学号和姓名的显示大小，满足不同投影或屏幕的需求。

### 💻 **二、全新形态：跨平台桌面应用 (Electron App)**

V5.7.4 最激动人心的升级，是推出了独立的桌面应用程序，文件名为 `学号抽取系统 5.7.4.exe` (Windows) 和 `学号抽取系统 Setup 5.7.4.exe` (安装包)，并支持全平台（Windows/Linux/Mac）。

#### 🌟 桌面应用的核心优势
1.  **独立运行，告别浏览器**：无需打开浏览器，双击即可启动，启动更快，操作更直接。
2.  **原生体验，性能更优**：作为独立的应用程序运行，资源占用更合理，动画和交互更加流畅。
3.  **系统级集成**：拥有独立的应用图标和任务栏/程序坞入口，更符合用户使用习惯。
4.  **全平台兼容**：无论您使用 Windows、macOS 还是 Linux，都能获得一致的卓越体验。

#### 📋 **8. 强大的“参数”菜单（全新功能）**

桌面应用最核心的创新是引入了**原生菜单栏**，并特别设计了 **“参数”** 选项卡，实现了**配置的导入、导出与持久化**。

*   **导出参数 (Ctrl+E)**：
    *   将您当前所有的配置（学号范围、抽取模式、是否不重复、字体大小、主题、甚至复杂的概率权重设置等）**一键导出为一个纯文本文件**（`.txt`）。
    *   这个文件本质上就是您在网页版中看到的URL参数（`?start=1&end=40&...`）。
    *   **用途**：方便您将精心配置好的方案保存下来，或分享给同事。

*   **导入参数 (Ctrl+I)**：
    *   选择之前导出的参数文件，点击导入。
    *   系统会**自动解析文件内容，并用这些配置重新加载整个应用**。
    *   **用途**：快速恢复之前保存的配置，或直接应用他人分享的完整方案，实现“配置即服务”。

> **技术揭秘**：这个功能的实现非常巧妙。它利用了 Electron 的 `loadFile` API，并通过传递 `query` 参数，将导出的配置直接注入到页面加载过程中，完美地解决了网页版中因初始化流程错误导致的URL同步失效问题，实现了终极的“配置还原”。
