

# 《智能学号抽取系统》V5.8.2 发布：从“好用”到“好玩”，“惊心动魄模式”引爆课堂！

**摘要：** 本文详细介绍了一款基于 Vue 3 构建的“智能学号抽取系统”的迭代历程。我们将采用**增量式**的方式，回顾系统从基础功能到 V5.8.2 版本的完整进化过程。本次更新的核心是推出了革命性的“**惊心动魄模式**”，通过可配置的闪烁动画，将随机抽取的悬念感和仪式感推向极致，为课堂互动带来了前所未有的趣味体验。

**关键词：** Vue 3, 前端开发, 教育技术, 随机抽取, 课堂互动, 惊心动魄模式, 动画效果, 代码分享, 版本迭代

---

#### 📌 一、项目简介

“智能学号抽取系统”旨在为教师提供一个公平、高效、有趣的课堂点名与随机分组工具。系统采用 **Vue 3 (Composition API)** 构建，结合 **XLSX.js** 库实现 Excel 文件解析，通过丰富的 CSS 动画和现代交互设计，打造了出色的用户体验。本文将带您一步步见证它的成长。

---

#### 📈 二、版本迭代：从基础到智能的增量式功能演进

我们按照功能演进的逻辑，将系统的发展分为几个关键阶段。

##### **阶段一：基础构建 (V5.7.3 之前)**

这是系统的雏形，提供了最核心的抽取功能。
*   **双模式操作**：
    *   **学号范围模式**：输入起始和结束学号，进行抽取。
    *   **名单导入模式**：支持上传 Excel 文件，解析学号和姓名。
*   **基础抽取模式**：
    *   **单次抽取**：点击一次，抽取一个。
    *   **快速抽取**：点击后学号快速滚动，再次点击停止。
*   **基础设置**：支持学号范围、是否不重复抽取等设置。

##### **阶段二：功能大爆发与交互革新 (V5.7.3)**

V5.7.3 是一次重大升级，系统从“工具”向“智能平台”迈进。
*   **新增“批量抽取”模式**：一次性抽取指定数量 (`batchSize`) 的不重复学生，结果以全屏动态效果展示，适用于组建小组。
*   **“连抽”模式重制**：不再是简单列表，而是升级为**沉浸式全屏动态效果**。每次抽取都有独立动画（翻转、弹入），过程充满悬念，结束后自动汇总结果。
*   **引入通用模态框 (Modal) 系统**：这是一个架构级的革新。将“删除”、“重命名”、“新建”等操作统一到一个美观、可复用的模态框中，交互更现代，代码更优雅。
*   **URL 参数同步权重**：一个关键增强！用户设置的“**概率权重**”（如1-10号权重80%）现在可以被编码到 URL 中，实现复杂配置的完美分享与还原。
*   **深色/浅色模式**：增加主题切换，提升夜间使用体验。

> **V5.7.3 总结**：功能全面，体验现代，但存在一个致命缺陷。

##### **阶段三：稳定性修复 (V5.7.4)**

V5.7.4 是一个至关重要的维护版本，解决了 V5.7.3 的核心 Bug。
*   **核心修复**：**修复了 URL 配置同步丢失的问题**。在 V5.7.3 中，当用户刷新页面或通过链接访问时，基础配置（如学号范围、抽取模式）无法被正确还原，导致“分享链接”功能失效。
*   **解决方案**：重构了 `onMounted` 生命周期内的初始化流程，确立了“**从 localStorage 加载 -> 应用 URL 参数 -> 执行其他初始化 -> 同步 URL**”的优先级，确保了配置的可靠持久化。

> **V5.7.4 总结**：修复了致命缺陷，为后续的功能创新打下了**稳定、可靠**的基础。至此，系统的核心功能和配置同步已完全就绪。

##### **阶段四：体验再升级，引爆互动乐趣 (V5.8.2)**

在 V5.7.4 的坚实基础上，V5.8.2 版本将重点放在了**提升用户体验和互动乐趣**上，推出了令人耳目一新的功能。

#### 🎉 三、V5.8.2 核心亮点：全新“惊心动魄模式”

如果说之前的版本解决了“**能不能用**”和“**好不好用**”的问题，那么 V5.8.2 则致力于回答“**好不好玩**”这个问题。

**1. 功能介绍**

*   **模式名称**：惊心动魄模式
*   **核心体验**：当您选择此模式并点击抽取后，系统不会立即显示结果，而是进入一个紧张刺激的“开奖”环节。
*   **过程描述**：被抽中的学号和姓名会开始**快速、随机地闪烁和跳动**。屏幕上的信息不断变化，悬念迭起，全班同学的目光都会被牢牢吸引。
*   **最终揭晓**：经过预设的闪烁次数后，画面骤然定格，最终的幸运儿（或“倒霉蛋”）伴随着庆祝动画（彩带飘落）震撼登场！
*   **适用场景**：特别适合评选“幸运之星”、决定“惩罚”对象、或在课堂尾声进行一次激动人心的总结性抽取，能瞬间点燃课堂气氛。

**2. 可配置的刺激感**

为了让体验更具个性化，我们加入了两个可调节参数：
*   **闪烁次数**：控制闪烁的总次数。您可以设置为 5 次的“小试牛刀”，也可以设置为 50 次的“持久拉扯”，悬念感由您掌控。
*   **闪烁频率**：控制闪烁的速度（单位：毫秒）。数值越小，闪烁越快，心跳越加速，紧张感越强。

**3. 技术实现 (Vue 3 Composition API)**

```javascript
// 1. 新增状态
const isTensionMode = ref(false); // 是否处于闪烁状态
const tensionIntervalId = ref(null); // 定时器ID
const tensionCount = ref(0); // 当前闪烁次数
const tensionMaxCount = ref(20); // 最大闪烁次数
const tensionSpeed = ref(100); // 闪烁速度

// 2. 核心方法
const startTensionMode = () => {
  if (isTensionMode.value) return; // 防止重复点击
  isTensionMode.value = true;
  tensionCount.value = 0;

  // 从可用学生中预先选定最终结果
  const finalResult = getWeightedRandomNumber();

  tensionIntervalId.value = setInterval(() => {
    tensionCount.value++;
    // 随机显示一个可用的学生（非最终结果）
    const randomIndex = Math.floor(Math.random() * available.length);
    currentNumber.value = available[randomIndex].student_id;
    currentStudent.value = available[randomIndex];

    // 达到最大次数，停止闪烁，显示最终结果
    if (tensionCount.value >= tensionMaxCount.value) {
      clearInterval(tensionIntervalId.value);
      isTensionMode.value = false;
      // 应用最终结果，触发动画和记录
      currentNumber.value = finalResult.student_id;
      currentStudent.value = finalResult;
      // ... (触发庆祝动画、添加到历史记录等)
    }
  }, tensionSpeed.value);
};
```

#### 🔧 四、其他优化与完善

V5.8.2 不仅带来了新功能，也对系统进行了全面的打磨：

*   **模态框应用扩展**：将 V5.7 版本引入的通用模态框系统，应用到了“清空当前名单”和“重置抽取记录”等操作中，交互更统一，防止误操作。
